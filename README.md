# Application Python de gestion des tâches

## Description
Application console simple permettant d’ajouter, d’afficher et de rechercher des tâches quotidiennes.

## Fonctionnalités
- 1 : Ajouter une tâche (refus des titres vides)
- 2 : Afficher toutes les tâches avec leur numéro
- 3 : Rechercher une tâche par mot-clé
- 0 : Quitter le programme

## Comment exécuter
1. Ouvrir le dossier du projet dans Visual Studio Code
2. Ouvrir le fichier `main.py`
3. Cliquer sur le bouton **Run Python File** (triangle en haut à droite)
